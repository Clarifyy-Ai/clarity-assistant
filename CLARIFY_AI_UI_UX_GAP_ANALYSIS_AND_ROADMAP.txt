CLARIFY AI — UI/UX REVIEW, GAP ANALYSIS & USER-FRIENDLINESS ROADMAP
================================================================================
Based on: "Clarify AI — Complete UI/UX Implementation Audit" (30 July 2026)
Goal stated by product owner: the WHOLE app should be simple and friendly to
use — on desktop AND mobile — and the core live-practice experience should
feel as fast, light, and frictionless as PARAKEET AI (a focused live-interview
copilot). This document reviews the existing audit, adds what's missing, and
gives a concrete plan to get there.

Implementation plan (Cursor): UI UX Roadmap — 5 sprints.
Locked decision: Overlay is the only mid-session UI; /app/live is setup +
post-session only (redirect into Overlay on session start).

1. TOP-LEVEL DIAGNOSIS — 6 ROOT CAUSES BEHIND MOST ISSUES
================================================================================

ROOT CAUSE 1 — Naming collisions confuse users before they even use a feature.
  Symptom: "Practice Coach" vs "Live" vs "Overlay" vs "Rehearsal" all refer to
  the same thing in different places; "Question Bank" (Prep Lab) vs "Answer
  Bank" (sidebar) are two different things with confusingly similar names;
  Analytics ("skills") vs Usage ("credits") aren't labeled clearly enough to
  tell apart.
  Fix once, fixes many: freeze ONE naming glossary (Section 7) and grep the
  whole codebase + copy for every alias, replacing with the canonical term.

ROOT CAUSE 2 — Two design systems coexist (legacy custom kit + shadcn/Radix).
  Symptom: dual Button/Card/Modal APIs, Toggle vs Switch mixing (with some
  Toggle instances miswired to checked/onChange — a real a11y bug, not just
  inconsistency), CSS bar charts on Analytics vs Recharts on Mock-Test
  Analytics, native <input>/<select> next to shared Input/Select.
  Fix once, fixes many: pick ONE kit (shadcn/Radix is more complete) and
  retire the custom primitives; one chart library everywhere.

ROOT CAUSE 3 — The core product (Practice Coach) has two competing UIs.
  Symptom: /app/live (in-shell, becomes an empty "status" page once the
  Overlay opens) vs /app/live/overlay (the actual experience). Users land on
  a page that visually looks broken once the real UI has moved elsewhere.
  Fix once, fixes many: make the Overlay THE product surface; the in-shell
  route should only ever be used for setup and the post-session summary —
  never a mid-session "nothing here" state.

ROOT CAUSE 4 — Long, multi-step setup before any value is delivered.
  Symptom: 5-step onboarding before first dashboard view; 6-step Practice
  Coach setup wizard before a session starts; long single-page Mock Test
  Configure form. Every extra step is a drop-off point.
  Fix once, fixes many: adopt a "2-minute rule" — a brand-new user should be
  able to start their FIRST practice session within 2 minutes of signup,
  with everything else offered as optional/advanced afterward. This is
  Parakeet AI's biggest structural advantage (see Section 4).

ROOT CAUSE 5 — Settings preferences are scattered across near-duplicate pages.
  Symptom: Notifications, Polish ("Advanced"), Privacy, and Data pages overlap
  on notification/retention controls; Security Config (a developer/Supabase
  checklist) sits inside consumer Settings; Profile page and Settings→Profile
  duplicate each other.
  Fix once, fixes many: consolidate into 5 groups (Account, Practice, Privacy
  & Security, Billing, Advanced) and move Security Config to Admin-only.

ROOT CAUSE 6 — Emoji is used as UI chrome instead of a proper icon system.
  Symptom: emoji in onboarding tiles, Prep tabs, Analytics tabs, Cookie
  Consent, Interview Day CTA, streak indicators.
  Fix once, fixes many: replace every chrome/tab/nav emoji with a Lucide (or
  equivalent) icon; reserve emoji, if at all, for celebratory toast copy only.

2. WHAT'S MISSING ENTIRELY (gaps, not bugs — there's no existing UI to fix)
================================================================================

CORE PRACTICE EXPERIENCE GAPS
  [ ] No "quick start" path that skips the 6-step wizard for a returning user
      who just wants to jump into another session with their last-used config.
  [ ] No visible, persistent "what will this cost me" credit estimate BEFORE
      starting a Practice Coach or Mock session — costs surface after the fact
      in some flows (e.g., Company Research auto-generate, mid-results AI
      analysis on Mock Test).
  [ ] No lightweight "listening/transcribing" confidence indicator during a
      live session — users can't easily tell if the mic is actually being
      picked up mid-conversation without checking a meter buried in a tab.
  [ ] No auto-generated post-session notes/summary comparable to what
      competitors offer (Parakeet AI auto-writes call notes + action items
      after every session — Clarify AI has Scorecard/Debrief but nothing
      framed as a quick digestible "here's what happened" note).
  [ ] No clear in-product answer to "will the interviewer be able to see
      this?" — stealth/compliance messaging exists but isn't presented as a
      simple confidence statement before a session starts.

ONBOARDING & FIRST-RUN GAPS
  [ ] No skip-and-explain pattern — skipping audio/resume steps in onboarding
      doesn't explain what the user loses by skipping.
  [ ] No visible "why we're asking" micro-copy next to role/experience/anxiety
      fields — feels like data collection rather than personalization.
  [ ] No first-session coach marks / tooltips inside the Overlay itself for a
      first-time user — the overlay's tab depth (hints/chat/resume/settings/
      audit) is thrown at users with no progressive reveal.

TRUST, SAFETY & HONESTY GAPS
  [ ] No visible, plain-language statement of "this is a practice tool, not
      for live/real deceptive use" reinforced consistently across every
      session-starting surface (partially present as a banner, not systemic).
  [ ] Push/digest notification toggles exist in UI but are admitted as not
      fully wired — this is a real user-trust risk if shipped as-is.
  [ ] No warning before a destructive action explains WHAT will be lost in
      plain language (several delete flows have no confirm at all — e.g.
      Interviews list hover-delete).

MOBILE-SPECIFIC GAPS
  [ ] No mobile-optimized Practice Coach path at all — the setup wizard and
      Overlay are both designed desktop-first; mobile only gets a "works
      best on desktop" notice rather than a real simplified flow.
  [ ] No swipe gestures anywhere (swipe-to-delete session/interview rows,
      swipe between Overlay tabs) — everything is tap/hover only, and
      hover-only delete actions are literally unusable on touch devices.
  [ ] No "Add to Home Screen"/PWA prompt despite a meaningful mobile audience
      implied by MobileNav, bottom tabs, and mobile-specific overlay notices.

CONTENT & GROWTH GAPS
  [ ] No branded chrome on the public Shared Debrief page — this is a growth
      loop (users share results) and currently looks unbranded/untrustworthy.
  [ ] No in-app changelog/what's-new surfacing tied to product updates.
  [ ] No native share sheet on Referrals (copy-link only) — a missed mobile
      conversion opportunity.

4. THE "PARAKEET AI STANDARD" — WHAT MAKES A LIVE-COPILOT FEEL SIMPLE
================================================================================
  P1. ONE-CLICK SESSION START — persist last-used config; "Start Practice
      (same setup)" primary, "Change setup" secondary.
  P2. THE OVERLAY IS THE WHOLE PRODUCT DURING A SESSION — redirect into
      Overlay; never leave an empty in-shell mid-session page.
  P3. MINIMAL VISIBLE CONTROLS — default hints/answer only; More tools for rest.
  P4. FAST, VISIBLE CONFIDENCE — persistent listening indicator.
  P5. AUTOMATIC WRAP-UP — 3-bullet summary immediately; full Scorecard optional.
  P6. SET-AND-FORGET CONTEXT — "Using: [Resume] · [Language]" chip always visible.
  P7. BROWSER-FIRST CAPABLE — desktop install is upgrade, not requirement.

BOTTOM LINE: setup once, live surface minimal, payoff immediate. Keep deeper
product surfaces (Mock, Prep, Gov Exams, Interview Day) but never in the way
of the core practice moment.

================================================================================
  "Practice Coach" ......... live AI practice (retire Live / Live Co-Pilot /
                              Rehearsal as user-facing terms)
  "Overlay" ................ floating session window (paired with Practice Coach)
  "Mock Interview" ......... free timed practice mode
  "Prep Lab" ............... STAR / Rephraser / Coding / System Design hub

                              naming inside Prep Lab for the same concept)

9. CLOSING SUMMARY
================================================================================
Clarify AI already has more depth than a focused tool like Parakeet AI.
The gap is FRICTION: too many setup steps, dual session UIs, naming drift,
and a mobile notice instead of a real path.

Sprint 1 and Sprint 2 alone — fixing the /app/live dead state, one-click
session start, and quieting the Overlay default — move the core practice loop
close to "open it and it just works," while keeping Clarify AI's deeper product.
