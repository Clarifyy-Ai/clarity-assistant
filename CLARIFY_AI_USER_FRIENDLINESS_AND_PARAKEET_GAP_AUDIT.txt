PART 9 — DEFINITION OF DONE: “FEELS LIKE PARAKEET”
================================================================================

Returning user (desktop) — ACCEPTANCE (code path exists):
  1. Click Practice Coach
  2. See Start Practice (same setup)
  3. Click once
  4. Land in Overlay listening (or Connect if permission missing)
  5. See Listening indicator + Using [Resume] chip
  6. Get hint/answer without hunting tabs (mobile: hints-only default)
  7. End → 3 bullet notes + Practice again
  8. Optionally Full Scorecard / Deep Debrief

New user — MOSTLY MET; polish in Part 10:
  1. Signup + short onboarding (≤ 2 required steps) — shipped direction
  2. Land on Coach or Dashboard with single CTA — shipped
  3. Resume select/skip with consequence — skip copy polish open
  4. Audio OK one-screen — PARTIAL (wizard connect step, not single badge)
  5. First hint without reading manual — improved; coach marks open

QA: If any step requires Guide first or an empty AppShell mid-session — FAIL.
