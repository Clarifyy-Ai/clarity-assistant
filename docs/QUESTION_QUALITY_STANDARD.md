# Question Quality Standard

## Publication states

Draft → Machine validated → Needs review → Expert reviewed → Approved → Rejected / Retired / Superseded

## Hard gates

- Blueprint totals (questions, marks, sections, duration, negative mark)  
- Single-correct MCQ: exactly one valid correct index  
- No duplicate options  
- No high near-duplicate within paper  
- Provenance / source class recorded  
- Correct paper class label (official previous vs AI-generated vs custom practice)

## Paid full-simulation packs

Require sufficient **approved** bank coverage for the exact pattern count. Do not fill slots with low-confidence AI items without review.
